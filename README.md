# cube_petit_knowledge — キューブぷちの教科書

すべてのキューブぷち(オレンジ・ピンク・これから生まれる子たち)が共通で学ぶ基礎知識。
**種としての知識**を置く場所であり、個体の記憶(日記・思い出・お友達)は置かない。

## 記憶の3層モデルにおける位置づけ

| 層 | 置き場所 | この repo? |
|---|---|---|
| 教科書(共通知識) | このリポジトリ(git配布、PRでレビュー) | ✅ |
| 個体の記憶 | 各個体のローカル `~/petit_claude/<名前>/`(+private mirror 例: cube_petit_orange_memories) | ❌ |
| 語り(共有される思い出) | cube_petit_cloud_memories(構想中) | ❌ |

## 使われ方

- 各個体の自律システム(cube_petit_autonomous_system)がこのリポジトリを pull し、
  tick 時に `lookup_knowledge(topic)` で**必要なときだけ**引く(全文をプロンプトに入れない)
- 「知識パック vX.Y で育った子」とバージョンで参照できるよう、節目でタグを打つ

## 書き方のルール

1. 1トピック1ファイル、`knowledge/` 配下。[INDEX.md](INDEX.md) に必ず載せる
2. 個体名・家庭の事情・人物情報を書かない(それは個体の記憶)
3. 更新は PR — 種の知識の進化をレビューする。個体の経験から昇格する知見は
   出典(どの子の、いつの経験か)をPR本文に書く
4. 短く、ロボット本人が読める言葉で(開発者向け文書は cube_petit_dev_guide へ)
